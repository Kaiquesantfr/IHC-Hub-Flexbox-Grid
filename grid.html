O que é o Grid?

O Grid organiza os elementos de dentro de uma caixa em linhas e colunas ao mesmo tempo, como uma tabela. Para ativar, aplicamos display: grid na caixa externa, e depois definimos como ela será dividida.

O encontro de uma linha com uma coluna se chama célula. Cada elemento ocupa uma célula da grade.

Display: grid

Ativa o grid. Sozinho, ele deixa os elementos em uma única coluna, cada um na sua linha. Para dividir em mais colunas, precisamos da propriedade da próxima seção.

Grid-template-areas

Permite desenhar a grade com nomes. Cada elemento recebe um nome com grid-area e a caixa define onde cada nome fica. É muito usado para montar o layout de uma página.
